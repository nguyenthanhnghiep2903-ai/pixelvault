# PixelVault 📷

> Thư viện hình ảnh miễn phí chất lượng cao — Clone của Pexels

## 🌐 Demo

[Xem trang web →](https://YOUR_USERNAME.github.io/pixelvault)

## ✨ Tính năng

- 🖼️ Masonry grid layout (Pinterest-style)
- 🔍 Tìm kiếm & lọc theo danh mục
- 📱 Modal xem ảnh chi tiết
- 🌙 Dark / Light mode
- ❤️ Like & lưu yêu thích
- ♾️ Load more ảnh
- 📲 Responsive trên mọi thiết bị

## 🛠️ Công nghệ

- HTML5 (Semantic)
- CSS3 (Vanilla — không dùng framework)
- JavaScript (Vanilla ES6+)
- Ảnh từ [Picsum Photos](https://picsum.photos)

## 🚀 Chạy local

Chỉ cần mở file `index.html` trong trình duyệt — không cần cài gì thêm!

## 📁 Cấu trúc

```
pixelvault/
├── index.html
├── css/
│   └── style.css
└── js/
    └── app.js
```
